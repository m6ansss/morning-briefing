시큐어 코딩 & 아이폰 설치

활성화된 보안 방어 계층

  • 외부 링크 HTTPS 전용 검증 (커스텀 스킴·사설 IP 차단)
  • 비재귀 선형 O(n) JSON 중첩 깊이(16단계)·크기(512KB) 제한
  • 정규표현식(ReDoS) 없는 O(n) HTML 정제 및 textContent 전용 DOM 렌더링
  • 허용된 공식 API 도메인 화이트리스트 & 10초 타임아웃

GitHub Pages 무료 배포 & 아이폰 설치

  1. ZIP 압축을 풀어 나온 index.html을 만들어 둔 GitHub 저장소에 업로드합니다.
  2. 저장소 Settings → Pages에서 main 브랜치를 선택해 무료 HTTPS 주소를 발급받습니다.
  3. 아이폰 Safari에서 해당 주소로 접속해 공유 → 홈 화면에 추가(웹 앱으로 열기 ON)를 누릅니다.
